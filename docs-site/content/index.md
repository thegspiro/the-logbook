# The Logbook Docs

Everything you need to learn and run The Logbook, the open-source intranet for
fire departments and emergency services: step-by-step training guides, setup
and administration instructions, videos and answers to common questions.

New to The Logbook? See [what it does](features.md) and
[why departments choose it](why.md).

## Start here

<div class="grid cards" markdown>

- **New to The Logbook?** Read
  [Getting Started](../../docs/training/00-getting-started.md) for your first
  sign-in, the dashboard and your account settings, then the
  [Glossary](../../docs/training/GLOSSARY.md) for the words the app uses.
- **Using it on your phone?**
  [Mobile & PWA Usage](../../docs/training/10-mobile-pwa.md) shows how to
  install The Logbook on an iPhone, Android phone or computer.
- **Learning a part of the app?** The
  [training guides](../../docs/training/README.md) cover every module, with a
  list of who should read what.
- **Installing or running a server?** Start with
  [Installation](../../wiki/Installation.md), then the
  [Unraid](../../wiki/Deployment-Unraid.md) or
  [Docker](../../wiki/Deployment-Docker.md) deployment guide.
- **Stuck?** Check the [FAQ](faq.md) and the
  [troubleshooting guide](../../docs/TROUBLESHOOTING.md).
- **Prefer to watch?** [Videos](videos.md) walk through common tasks.

</div>
