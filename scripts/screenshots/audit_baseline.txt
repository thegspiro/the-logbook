# --- Post-move modal captures (added 2026-08-18) -----------------------------
#
# Both were captured AFTER the 2026-08-15 canvas move, so the explanation above
# does not cover them: nothing about them is stale. Both were opened and read
# before being listed here.
#
# The modal case is structural, not a capture defect. A dialog's scrim is
# `position: fixed; inset: 0`, and a fixed box is laid out against the initial
# containing block, which excludes the scrollbar gutter that
# `scrollbar-gutter: stable` reserves on the root. The scrim therefore stops
# 15px short of the window edge by definition, and the gutter keeps showing the
# root gradient underneath. The canvas move fixed the original defect — that
# strip is no longer the browser's default white — but on a light page under a
# dark scrim a pale gradient against a dimmed page still trips the luma check.
#
# So, unlike every entry above, RE-CAPTURING THESE WILL NOT CLEAR THEM, and any
# future modal screenshot on a light page will land here too. That makes this
# section a growing list rather than a shrinking one, which is the opposite of
# what this file is for; the durable fix is for `check_unpainted_gutter` to stop
# reporting the subtle light-page-under-scrim tier, which would retire most of
# the block above along with these two. Left as-is here because that is a change
# to the check's contract, not a screenshot fix.
#
# UPDATE 2026-08-24 — the STARK tier now has no cause left.
#
# `html` carried the themed gradient as a background *image* and, because the
# `background:` shorthand resets it, no background *colour*. The reserved gutter
# is painted from the canvas colour, which an image does not supply — so it fell
# back to the browser's white, and every dark-mode page carried a bright 15px
# strip. The 2026-08-15 canvas move did not fix that; it swapped one image for
# another. `styles/index.css` now sets `background-color` on the root as well,
# and a re-captured dark page paints the gutter in the theme colour
# (`19-11-dark-scrollbar-gutter` was flagged STARK and is not flagged now).
#
# That leaves the subtle tier reporting exactly one thing, forever: a scrim
# cannot dim a strip that is outside the box it is laid out against. It is a
# constant, not a regression signal — which strengthens the recommendation above
# rather than replacing it. Still not enacted here: retiring a tier changes the
# check's contract for everyone, and this branch is a screenshot pass.
#
# The five below are that class, added 2026-08-24: light pages under a dialog
# scrim, re-captured after the canvas fix and still flagged, as predicted. The
# last two are the Call Volume pair, which renders inside a report dialog — one
# ordinary capture of an ordinary screen, landing here purely because it has a
# scrim. That is the growth this section was warned about: seven entries now,
# and every future modal shot on a light page joins them.
