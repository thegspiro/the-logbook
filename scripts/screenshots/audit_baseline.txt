# Screenshot audit baseline — images already known to be flagged.
#
# EMPTY IS THE CORRECT STATE. Nothing in docs/training/images is flagged as of
# 2026-09-06, and this file is kept rather than deleted so the mechanism and its
# format survive for the next finding.
#
# HOW TO USE THIS FILE
#   - A new finding fails CI. Re-capture the image, or add its bare filename
#     here with a note saying why it is acceptable.
#   - Re-capture an image, then DELETE its line. CI fails on a stale entry,
#     which is deliberate: it keeps this list shrinking instead of quietly
#     suppressing real regressions on those exact files forever.
#   - Blank lines and `#` comments are ignored.
#
# WHY IT IS EMPTY — the short version of a long argument
#
# This file held 42 entries until 2026-09-06, and every one of them was the same
# thing: a light-mode page under a dialog scrim, showing a pale 15px strip in the
# scrollbar gutter. That was never fixable by re-capturing. A scrim is
# `position: fixed; inset: 0`, and a fixed box is laid out against the initial
# containing block, which excludes the gutter `scrollbar-gutter: stable` reserves
# on the root — so the scrim stops 15px short of the window edge by definition
# and the gutter keeps showing the root gradient beside a dimmed page.
#
# The check reported it anyway, as a "subtle" tier beside the "STARK" one. So the
# list grew with every modal screenshot the guides gained, which is the opposite
# of what a baseline is for: 5 entries, then 7, then 8, then 42. The last full
# screenshot pass re-captured 424 images and produced exactly two findings, both
# of them this. At that point the check was reporting its own blind spot in
# proportion to how much honest work was being done.
#
# The real defect the STARK tier existed for — `html` carrying a background
# *image* and no background *colour*, so the reserved gutter fell back to the
# browser's white and every dark page wore a bright strip — was fixed on
# 2026-08-24 by setting `background-color` on the root. The subtle tier was
# retired on 2026-09-06, and `check_unpainted_gutter` now reports dark pages
# only. The note beside that return explains what the narrowing gives up and why
# a light-page-only regression cannot occur on its own.
#
# The full history, including the three sessions that each added to this list
# without anyone doing anything wrong, is in this file's git history and in
# docs/training/SCREENSHOT_CURRENCY.md.
#
# See scripts/screenshots/README.md → "When something outside the guides
# invalidates a shot".
