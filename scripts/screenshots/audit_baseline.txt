# Screenshot audit baseline — images already known to be flagged.
#
# EMPTY, as of 2026-09-06, and that is the finished state rather than a gap.
#
# It held 42 entries, and 41 of them were one thing: a light-mode page captured
# under a modal scrim. `check_unpainted_gutter` reported those as a "subtle"
# tier, and the tier has been retired, so none of them flags any more. Deleting
# a line whose image no longer flags is what the rules below have always said
# to do; this is that, done 42 times in one go.
#
# WHY THE TIER WENT
#
# A dialog's scrim is `position: fixed; inset: 0`, so it is laid out against the
# initial containing block — which excludes the gutter that
# `scrollbar-gutter: stable` reserves on the root. The scrim stops 15px short of
# the window edge *by definition*, and the root gradient shows through. No
# capture can avoid it, which is why re-shooting never cleared these entries and
# why this list could only ever grow.
#
# So the tier reported one constant, forever, and charged a CI failure for every
# new modal screenshot. On 2026-09-06 that came due: a routine refresh of 424
# captures (#2320) turned `main` red and blocked four unrelated PRs, whose
# authors had touched no image and could not clear it — re-capture does not
# work, and editing the check is not a screenshot task. Three sessions had
# already recommended retiring the tier in this file and each declined, on the
# grounds that it changes the check's contract for everyone. It does. It was
# still the right change, and #2320 is what made the cost of deferring it
# visible.
#
# The dark-page (STARK) tier stays. It has had no cause since 2026-08-24, when
# `styles/index.css` began setting `background-color` on the root so a dark
# capture paints the gutter in the theme colour — but unlike the subtle tier it
# describes a real defect, and one a re-capture can actually fix.
#
# HOW TO USE THIS FILE
#   - Re-capture an image, then DELETE its line here. CI fails on a stale entry,
#     which is deliberate: it keeps this list shrinking instead of quietly
#     suppressing future regressions on the same files.
#   - Do not add a line to silence a new finding without saying why. A new
#     finding means something changed that nobody looked at. With the subtle
#     tier gone, a finding is now a dark page whose gutter went unpainted —
#     worth re-shooting rather than recording.
#
# See scripts/screenshots/README.md → "When something outside the guides
# invalidates a shot", and docs/training/SCREENSHOT_CURRENCY.md.
